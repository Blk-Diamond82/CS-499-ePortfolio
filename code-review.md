# CS 499 Code Review

## Travlr Full Stack Application

As part of my Computer Science Capstone, I completed a code review of the
Travlr Full Stack application originally developed in CS 465: Full Stack
Development with MEAN.

The code review examines the existing application architecture and identifies
opportunities for improvement across the three enhancement areas required for
my ePortfolio:

- Software Design and Engineering
- Algorithms and Data Structures
- Databases

During the review, I evaluate the application's existing functionality,
organization, and data management while outlining the enhancements that will
be implemented throughout the capstone.

## Planned Enhancements

The Travlr application will serve as the foundation for all three ePortfolio
enhancements. This allows the portfolio to demonstrate the progression of one
application as its architecture, functionality, data handling, and overall
design are improved.

### Software Design and Engineering
Enhance the application's architecture and separation of concerns while
improving maintainability and scalability.

### Algorithms and Data Structures
Improve how trip data is processed and presented by implementing search,
filtering, and sorting functionality within the administrative SPA.

### Databases
Enhance the application's MongoDB data layer and database operations to
demonstrate effective data management within a full stack application.
